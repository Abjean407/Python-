My journal of upskilling the programming language Python3

## Practice Files

- `flow.py` — Practice with Python flow control, user input, variables, and conditional statements.
- `while.py` — Practice creating variables, working with strings, stripping whitespace, and removing prefixes and suffixes.
- `lists.py` — Practice creating and accessing lists, using indexes, formatting list values, changing and adding items, removing items with `del`, `.pop()`, and `.remove()`, organizing lists with `.sort()` and `.reverse()`, and checking list length with `len()`.
